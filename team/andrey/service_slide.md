**Как проверить за 5 минут**
1. Открыть бота → «Начать» → «Я работодатель». Профиль компании → опубликовать стажировку.
2. Сразу видно список кандидатов с процентом совпадения и расшифровкой → «Пригласить» → бот присылает контакты.
3. На главном экране переключиться на «Я студент» → согласие, номер в один тап, анкета → лента подходящих стажировок → «Интересно».

Один аккаунт MAX проходит обе роли. Тестовые студенты и компании помечены «демо».

**Тестовые логины:** не нужны — вход через аккаунт MAX проверяющего.

**Запуск у себя:** `cp .env.example .env` → `MAX_BOT_TOKEN`, `POSTGRES_PASSWORD` → `docker compose up --build`
(с нуля ~30 с, замер в CI). Для проверки через MAX нужен токен бота — у команды.

**Внешние сервисы:** MAX Bot API и MAX Bridge (в Docker не поднимаются).
