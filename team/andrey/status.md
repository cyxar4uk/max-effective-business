## Сделано

- Каркас `apps/server` (ветка `andrey/server-skeleton`, PR в `main`): Node 24 + TypeScript, Express 5, TypeORM,
  zod, pino, vitest, ESLint. Команды: `npm run dev|build|test|typecheck|lint`.
- Схема БД — первая миграция: `users`, `skills`, `student_profiles`, `employers`, `internships`, `interests`,
  `notifications`. Миграции применяются при старте сервера. Проверено на PostgreSQL 18.
- Проверка подписи `initData` по dev.max.ru на каждом запросе к `/api`, заголовок `X-Max-Init-Data`, 12 юнит-тестов
  (включая эталонный вектор, посчитанный отдельно на Python).
- Скрипт режима разработки `npm run dev:init-data` — подписанный `initData` для браузера и curl.
- Готовы эндпоинты: `GET /api/health`, `GET /api/me`, `POST /api/me/consent`, `GET /api/skills`.
- Единый формат ошибок, лимит запросов, CORS по `MINIAPP_URL`, helmet; в логах нет `initData` и заголовков.
- Внутренняя шина событий `src/events.ts` для модуля бота.
- Контракт API — `docs/api.md` (черновик на согласование).
- `Dockerfile` сервера, `compose.yaml` (`db` + `server`), `.env.example` со всеми переменными, CI на GitHub Actions.

- PR #2 (`andrey/api-endpoints`, поверх PR #1): **все эндпоинты из `docs/api.md`** — анкета студента, профиль
  компании, стажировки (создание, список, изменение, закрытие), лента, отклики, кандидаты, приглашение и отказ,
  «Мои отклики», телефон с проверкой подписи `requestContact`. Права: работодатель видит только своих кандидатов,
  телефон и фамилия студента — только после приглашения. Конечный автомат откликов, идемпотентность, защита от
  параллельных запросов, события после записи в БД.
- Сквозной тест сценария на PostgreSQL (12 проверок) в CI; всего 44 теста.
- `npm run dev:contact` — подписанный номер для работы вне MAX.

- PR #3 (`andrey/deploy`, поверх #2): вебхук бота `POST /bot/webhook` с проверкой секрета; прод-конфигурация
  `compose.prod.yaml` + Caddy (HTTPS автоматически, наружу только 80/443); `scripts/deploy.sh` — выкатка одной
  командой; `scripts/max-webhook.sh` — подписка бота на вебхук; `docs/deploy.md`; технические разделы README;
  проверка истории git на секреты (gitleaks) в CI — утечек нет.
- Исправлено в #1: пустой `MINIAPP_URL` из compose ронял запуск сервера.
