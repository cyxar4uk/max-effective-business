# Правки к справочнику навыков

Черновик Артёма к справочнику Тимура (`apps/server/src/seed/skills.ts`, 73 навыка). Формат — по
[skills_format.md](../timur/skills_format.md). Коды существующих навыков не трогаем.

**Статус:** согласовано Артёмом 28.09. Тимур переносит правки в `skills.ts`.

## Почему правки

Основной пользователь — владелец малой компании без HR. Ему нужен человек на сайт, аналитику, маркетплейсы,
1С или соцсети. В черновике хорошо закрыты направления РАНХиГС, но почти нет задач малого бизнеса:
маркетплейсов, конструкторов сайтов, 1С для торговли. Без них совпадение по таким местам будет 0 % или 100 %.

## 1. Новая группа «Маркетплейсы и онлайн-продажи»

Ставим второй по порядку, после «Аналитики и данных».

| Код | Название |

| `unit_economics` | Юнит-экономика |
| `avito` | Продвижение на Авито |
| `product_photo` | Предметная фотосъёмка |

## 2. Добавить в существующие группы

| Код | Название | Группа |
|---|---|---|
| `email_marketing` | Email-рассылки | Маркетинг и PR |

## 3. Переименовать (коды те же)

| Код | Было | Стало | Почему |
|---|---|---|---|
| `no_code` | No-code (Tilda, конструкторы) | Tilda и конструкторы сайтов | владелец ищет «сделать сайт», а не «no-code» |
| `web_analytics` | Веб-аналитика | Веб-аналитика (Яндекс Метрика) | понятно, что именно умеет студент |
| `context_ads` | Контекстная реклама | Контекстная реклама (Яндекс Директ) | то же |

## 4. Оставляем как есть

- «Логистика и агро»: нужна для шага масштабирования на аграрные вузы.
- МСФО, инвестиционный анализ, госзакупки: малому бизнесу нужны редко, но студенты этих направлений должны
  найти свои навыки в анкете.

**Итого: 73 + 14 = 87 навыков в 12 группах.**

## 5. Теги задач — черновик, как реализовать, решают разработчики

Тег задачи в карточке места подставляет навыки в форму работодателя, работодатель их правит. Студент
фильтрует ленту по тегу.

| Тег | Навыки, которые подставляются |
|---|---|
| Сайт | `no_code`, `wordpress`, `html_css`, `seo` |
| Маркетплейсы | `marketplace_cards`, `wildberries`, `ozon`, `product_photo`, `unit_economics` |
| 1С | `1c_accounting`, `1c_trade`, `1c_programming` |
| Соцсети и реклама | `smm`, `copywriting`, `targeted_ads`, `canva`, `video_editing` |
| Таблицы и аналитика | `excel`, `google_sheets`, `data_visualization`, `power_bi` |
| Продажи и клиенты | `sales`, `crm`, `avito`, `customer_support` |
