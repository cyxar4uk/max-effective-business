# Артём, это для тебя

Твой Claude настроен как продуктовый партнёр: он вытаскивает из тебя концепцию, задаёт много вопросов, спорит от
лица жюри и превращает твои решения в спецификации и задачи для команды. Решаешь ты.

## Как начать

1. Поставь GitHub CLI и войди (нужно, чтобы Claude мог ставить задачи людям):
   ```bash
   winget install GitHub.cli
   gh auth login
   ```
2. Склонируй репозиторий и открой Claude Code в своей папке:
   ```bash
   cd team/artyom
   claude
   ```
3. Напиши: «Привет, начинаем. Что сейчас важнее всего?»

## Как работать голосом

1. Когда появилась мысль, **запиши голосовое на телефон**: 2–10 минут, одна тема. Можно на ходу.
2. Получи расшифровку: например, отправь голосовое себе в «Избранное» в Telegram и нажми «Расшифровать», или
   используй любой диктофон с расшифровкой.
3. Скинь текст Claude: вставь в чат или положи файлом в `team/artyom/inbox/`. Эта папка в git не попадает.
4. Claude перескажет, что понял, покажет противоречия и задаст вопросы. **Отвечай тоже голосом** — следующей записью.
5. Когда решение принято, Claude запишет его в документы и предложит задачи для команды. Задачи создаются только после твоего «да».

Если не знаешь, о чём говорить, спроси Claude: «Дай тему для голосового». Он предложит 3–5 вопросов на 5 минут.

## Что от тебя ждёт команда в первую очередь

- Дедлайн, бот, ник бота и второй бот для разработки — от организаторов.
- Ответы центра карьеры, особенно про документы для чек-листа.
- Решения по вопросам, которые блокируют экраны: Claude собирает их в `questions.md`.
- Справочник навыков к обеду 28.09 (вместе с Тимуром).
