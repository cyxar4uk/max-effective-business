# Артём: как начать

## Перед началом (5 минут)

1. Установи GitHub CLI и войди под своим аккаунтом `Odin2tree4`:
   ```bash
   winget install GitHub.cli
   gh auth login
   ```
2. Склонируй репозиторий:
   ```bash
   git clone https://github.com/cyxar4uk/max-effective-business.git
   ```
3. Открой Claude Code в своей папке:
   ```bash
   cd max-effective-business/team/artyom
   claude
   ```
4. Скопируй сообщение ниже целиком и отправь Claude первым.

В этой первой сессии:
