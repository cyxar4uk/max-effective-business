# Тимур: как начать

## Перед началом (5 минут)

1. Установи GitHub CLI и войди под своим аккаунтом `Krasatim`:
   ```bash
   winget install GitHub.cli
   gh auth login
   ```
   (macOS: `brew install gh`)
2. Склонируй репозиторий и открой Claude Code **в корне**, чтобы он видел `apps/`:
   ```bash
   git clone https://github.com/cyxar4uk/max-effective-business.git
   cd max-effective-business
   claude
   ```
3. Скопируй сообщение ниже целиком и отправь Claude первым.

## Первое сообщение для Claude

```text
Привет. Я Тимур — бэкенд в команде на хакатоне MAX. Мы делаем бот центра карьеры в MAX для стажировок. На мне бот и уведомления, расчёт совпадения студента и стажировки, тестовые данные и импорт из «Работа России».

Прочитай целиком: CLAUDE.md в корне, team/timur/CLAUDE.md (это твоя инструкция), docs/03_product.md (особенно «Основной сценарий», «Бот», «Расчёт совпадения», «Данные»), docs/05_max_platform.md и docs/04_criteria_map.md (строки с Тимуром).

Сначала проверь мои задачи: gh issue list --assignee @me --state open. Если пусто — работаем по стартовому плану из моей инструкции.

В первой сессии:
1. Перескажи в 5 пунктах мою зону, с кем я стыкуюсь (Андрей, Илья, Артём) и что им от меня нужно в первую очередь.
2. Изучи документацию MAX Bot API и официальный SDK @maxhub/max-bot-api. Ответь со ссылками: как кнопка open_app открывает мини-приложение и передаёт startapp-параметр; как получить user_id для отправки сообщения; можно ли писать пользователю после /start; точный формат заголовка Authorization. Всё найденное допиши в docs/05_max_platform.md.
3. Расчёт совпадения: чистые функции и юнит-тесты по правилам из docs/03_product.md, в apps/server/src/matching/. Если каркаса сервера Андрея ещё нет в main — пиши код и тесты там же, но package.json не трогай; подключим тест-раннер, когда каркас зальётся.
4. Предложи формат справочника навыков (структура + 10 примеров), чтобы Артём заполнил его к обеду завтра.
5. Набросай план тестовых данных: сколько работодателей, стажировок и студентов, чтобы у любой стажировки были кандидаты с разным процентом совпадения.

Работай в ветке timur/matching. Методы Bot API — только проверенные по документации. В конце сессии обнови team/timur/status.md: что готово и что нужно от Андрея и Артёма. Закоммить и запушь.
```
