## Шаги (Андрей)

```bash
# 1. Резервная копия — на случай отката
git clone --mirror git@github.com:cyxar4uk/max-effective-business.git meb-backup.git

# 2. Рабочая копия
git clone --mirror git@github.com:cyxar4uk/max-effective-business.git meb.git
cd meb.git
```

**3. Переписать сообщения** — один из вариантов.

А. `git filter-repo` (рекомендуют сами git; `pip install git-filter-repo`):

```bash
git filter-repo --refs $(git for-each-ref --format='%(refname)' refs/heads) --message-callback '
import re
return re.sub(rb"(?im)^co-authored-by:.*(claude|anthropic).*$\n?", b"", message).rstrip() + b"\n"
'
```

Б. Встроенный `git filter-branch` — **проверен пробным прогоном**:

```bash
FILTER_BRANCH_SQUELCH_WARNING=1 git filter-branch -f --msg-filter \
  "sed -E '/^[Cc]o-[Aa]uthored-[Bb]y:.*([Cc]laude|[Aa]nthropic)/d'" -- --branches
```

```bash
# 4. Проверка: должно быть 0
git log --branches -i --grep='co-authored-by:.*\(claude\|anthropic\)' --oneline | wc -l

# 5. Отправить только ветки. НЕ --mirror: служебные refs/pull GitHub отклонит
git push --force origin 'refs/heads/*:refs/heads/*'
```

(После варианта А, если filter-repo убрал `origin`: `git remote add origin git@github.com:cyxar4uk/max-effective-business.git`.)

## После — каждому участнику

```bash
git fetch origin --prune
git checkout main && git reset --hard origin/main
# для каждой своей ветки, которая есть на GitHub:
git branch -f <ветка> origin/<ветка>
```

Проще — склонировать заново. Незапушенные коммиты: `git cherry-pick` их на новую ветку. **`git pull` без reset не
делать** — он смешает старую историю с новой, и подпись вернётся.

## Что ещё знать

- **Открытые PR** (#45, #46, #47) останутся открытыми: их ветки переписываются тем же прогоном. Одобрения
  сохраняются, если в настройках не включён сброс ревью при новых коммитах.
- **Сервер:** `scripts/deploy.sh` делает `fetch` + `reset --hard origin/<ветка>` — переписанную историю примет сам.
- **Страницы уже влитых PR** (#5, #7–#11 и другие) продолжат показывать старые коммиты: GitHub хранит их в служебных
  `refs/pull/*`, пушем их не изменить (удалить может только поддержка GitHub). В обычный `git clone` они не попадают —
  у жюри история будет чистой.
- **Список участников** на главной репозитория пересчитывается GitHub с задержкой.
- Новые подписи не появятся: пустой `attribution` в `.claude/settings.json` и правило в `CLAUDE.md`; у Тимура ещё
  локальный хук `commit-msg`, который не даёт закоммитить `Co-Authored-By: Claude`.
