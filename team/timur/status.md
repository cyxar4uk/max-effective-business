## Сделано

- **Bot API сверен с документацией**, дописано в [docs/05_max_platform.md](../../docs/05_max_platform.md#bot-api):
  - домен — `https://platform-api2.max.ru` (старый `platform-api` устарел);
  - заголовок — `Authorization: <токен>`, без `Bearer`;
  - кнопка `open_app`: `{ type, text, web_app: "<ник_бота>", payload }`, payload до 512 символов `[A-Za-z0-9_-]`;
  - `user_id` приходит в событии `bot_started` (`user.user_id`) и в `message_created` (`message.sender.user_id`);
    после `/start` бот может писать сам, `403` — пользователь остановил бота;
  - лимиты: 2 сообщения в секунду в один диалог, 30 запросов в секунду на весь API.
- **Расчёт совпадения** в `apps/server/src/matching/`: чистые функции `matchStudentToInternship`, `checkFilters`,
  `computeScore`, `shouldNotify` и `matcher` по контракту `Matcher` Андрея. **Подключён вместо `temporaryMatcher`**
  в `src/index.ts` и в сквозном тесте. У временной была ошибка: при одних желательных навыках без совпадений — 70 % вместо 0 %.
  `typecheck`, `lint`, 65 юнит-тестов зелёные; сквозной тест на PostgreSQL проверяет CI (локально нет Docker).
- **Справочник навыков — черновик, 70 навыков в 11 группах**: `apps/server/src/seed/skills.ts`. Грузится при каждом
  старте сервера после миграций, одним запросом с upsert по коду — повторный старт дублей не создаёт.
  Правила для Артёма: [skills_format.md](skills_format.md).
- **Демо-данные** (`apps/server/src/seed/demo/`): 12 вымышленных работодателей, 26 стажировок в шести направлениях,
  36 студентов, 59 откликов со статусами «интересно», «приглашён», «отказ». Процент в откликах считает тот же расчёт.
  Тест проверяет, что у каждой стажировки есть подходящие кандидаты с ≥ 80, 60–79 и < 60 %.
  Загрузка — при `SEED_DEMO=true` (в `compose.yaml` по умолчанию) или `npm run seed:demo`; повторная не создаёт
  дублей и не откатывает действия проверяющего. План — [seed_plan.md](seed_plan.md).

## Проверить на живом боте (когда будет токен)

- `payload` кнопки `open_app` приходит в `start_param` мини-приложения.
- `user.id` из `initData` совпадает с `user_id` в Bot API.
- Бот может написать пользователю, который открыл мини-приложение по `?startapp=`, но не нажимал «Начать».

## Для бота (на заметку)

- Демо-пользователям (`max_user_id < 0`) бот сообщений не шлёт — это не настоящие аккаунты MAX.
- Демо-отклики не публикуют `interest.created`, поэтому бот не пришлёт проверяющему пять уведомлений разом.
  Если Артём захочет, чтобы жюри увидело уведомление «новый заинтересованный студент», — можно слать одно сводное.
