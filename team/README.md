# Папки участников

У каждого участника своя папка:

| Файл | Что это |
|---|---|
| `CLAUDE.md` | инструкция для твоего Claude: роль, зона, стартовый план, «готово, когда», с кем стыкуешься |
| `status.md` | твой статус: что сделано, что дальше, блокеры, что нужно от других. Обновляется в конце каждой сессии |
| остальное | твои рабочие материалы: заметки, исследования, черновики |
| `inbox/` | сырые голосовые и расшифровки. **В git не попадает**, живёт только у тебя на компьютере |

У Артёма в папке ещё `README.md` лично для него: как работать со своим Claude голосом.

## Как запускать Claude

**Работаешь в основном с документами** (Артём) — запускай Claude Code из своей папки:

```bash
cd team/artyom
claude
```

**Пишешь код** (Андрей, Тимур, Илья) — запускай из корня репозитория, чтобы Claude видел `apps/`:

```bash
claude
```

Первой фразой напиши, кто ты: «Я Андрей». Claude прочитает `team/andrey/CLAUDE.md`.

## Задачи

- Задачи ставит **Артём** в GitHub Issues. Его Claude готовит их из спецификаций фич, Артём подтверждает.
- У каждого одна очередь: `gh issue list --assignee @me --state open`. Claude проверяет её в начале сессии.
- Взял задачу — «Беру» в комментарии. Вопрос — комментарием в задаче. Сделал — PR с `Closes #номер`.
- Правила целиком — раздел «Задачи» в корневом `CLAUDE.md`.

Нужен GitHub CLI: `winget install GitHub.cli` (Windows) или `brew install gh` (macOS), затем `gh auth login`.

## Как синхронизироваться

1. Начало дня: `git pull`, задачи из Issues, `status.md` остальных. Claude может сделать это за тебя: «что у меня сегодня?»
2. Конец сессии: попросить Claude обновить твой `status.md`, закоммитить и запушить.
3. Ждёшь чего-то от другого — пиши в задаче или в разделе «Нужно от других» своего статуса **и** напиши человеку лично.
