# Папки участников

У каждого участника своя папка:

| Файл | Что это |
|---|---|
| `CLAUDE.md` | инструкция для твоего Claude: роль, задачи, зоны, с кем стыкуешься, «готово, когда» |
| `status.md` | твой статус: что сделано, что дальше, блокеры, что нужно от других. Обновляется в конце каждой сессии |
| остальное | твои рабочие материалы: заметки, исследования, черновики |

## Как запускать Claude

**Вариант 1. Работаешь в основном с документами** (Артём). Запускай Claude Code из своей папки:

```bash
cd team/artyom
claude
```

Загрузятся общий `CLAUDE.md` из корня и твой личный.

**Вариант 2. Пишешь код** (Андрей, Тимур, Илья). Запускай из корня репозитория, чтобы Claude видел `apps/`:

```bash
claude
```

Первой фразой напиши, кто ты: «Я Андрей». Claude прочитает `team/andrey/CLAUDE.md`.

## Как синхронизироваться

1. Начало дня: `git pull`, затем прочитать `status.md` остальных. Claude может сделать это за тебя: «прочитай статусы команды».
2. Конец сессии: попросить Claude обновить твой `status.md`, закоммитить и запушить.
3. Чего-то ждёшь от другого — пиши в разделе «Нужно от других» своего статуса **и** напиши человеку лично.
