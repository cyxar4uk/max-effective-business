# Живая проверка мини-приложения в MAX

Дополняет регламент Андрея [team/andrey/live_check.md](../andrey/live_check.md) (сервер, вебхук, подпись данных).
Здесь — то, что видит проверяющий в мини-приложении. Проверяем с телефона через мобильный интернет: из офисной
сети сервер по 80/443 не открывается.

## 0. Перед проверкой

- [ ] Прод выкачен из `main`, `https://tandem.anyway-community.ru` открывает мини-приложение, `/api/health` — `ok`.
- [ ] Адрес мини-приложения `https://tandem.anyway-community.ru` отправлен организаторам в форму
      https://sbor-ssylok-dlya-mini-prilojeniy.testograf.ru/ — бот `t373_hakaton_max_bot` выдан ими, прописать адрес
      в его настройках (business.max.ru) можно только из их кабинета.
- [ ] В боте нажато «Начать» с того аккаунта, которым проверяем.

## 1. Запуск и платформа

- [ ] Кнопки бота «Я студент» и «Я работодатель» открывают мини-приложение в нужном разделе (`start_param`).
- [ ] Кнопка из уведомления компании открывает кандидатов места (`internship_<id>`, `isOwner`).
- [ ] Кнопка «Назад» MAX появляется на вложенных экранах и возвращает назад; на корневых экранах её нет.
- [ ] Тема повторяет тему MAX/устройства; шрифты Unbounded и Onest загрузились.
- [ ] Нет горизонтального скролла, нижняя навигация и закреплённые кнопки не заходят под системные панели.

## 2. Сценарий одним аккаунтом (как в README)

- [ ] Согласие → «Поделиться номером»: окно MAX с номером, после подтверждения сервер принимает подпись
      (в логе сервера `contactScheme` — какая схема подписи сработала).
- [ ] Профиль компании → форма места (8 шагов) → «Опубликовать» → счётчик откликов растёт.
- [ ] Кандидаты: тестовые отклики с плашкой, фраза совпадения, «Пригласить» с отменой 5 с.
- [ ] Студент: своё место первым в колоде, свайп и кнопки, «Вернуть».
- [ ] Пригласить себя → «Это тандем!» у компании и у студента; бот присылает обе стороны сообщения.

## 3. Мелочи MAX, которые не проверить в браузере

- [ ] Тактильный отклик при «Интересно», публикации и «Это тандем!».
- [ ] «Скопировать номер» копирует (буфер обмена во встроенном браузере MAX).
- [ ] «Позвонить» (`tel:`) открывает набор номера; если нет — хватает «Скопировать номер».
- [ ] «Открыть бота» (`openMaxLink`) открывает чат с ботом.
- [ ] Веб-версия MAX на компьютере: мини-приложение открывается, десктопная раскладка, клавиши ← → Z.

## 4. Режим ярмарки (QR, #18)

- [ ] Сканер в колоде (`openCodeReader`): код места открывает карточку; закрыть сканер без кода — никаких
      сообщений (если всплыло «Не получилось открыть сканер» — записать код ошибки клиента).
- [ ] «Поделиться в MAX» на экране QR и иконка на карточке места открывают шеринг MAX с текстом и ссылкой.
- [ ] Камера телефона вне MAX → QR с экрана «QR для стенда» → MAX открывает мини-приложение сразу на месте
      (аккаунтом, который не публиковал это место); без анкеты: согласие → анкета → снова место → «Интересно» →
      отклик у компании.
- [ ] Владелец сканирует свой плакат камерой → кандидаты с плашкой «Вы открыли ссылку на своё место» →
      «Посмотреть как студент» → карточка места → «Назад» MAX → снова кандидаты; закрытая плашка больше не появляется.
- [ ] Веб-версия MAX: сканер даёт выбрать файл (скриншот QR) и открывает место.
- [ ] «На весь экран» закрывается кнопкой «Назад» MAX; тактильный отклик при удачном и чужом коде.

## 6. Съёмка для презентации и видео (#19) — сразу после одобрения бота

Снимаем с телефона в светлой теме, скриншоты — встроенным способом телефона, без чужих уведомлений в строке состояния.
Порядок совпадает со сценарием, поэтому всё снимается за один проход, минут за 15.

| № | Кадр | Куда идёт |
|---|---|---|
| 1 | Чат с ботом: приветствие и кнопки «Я студент» / «Я работодатель» | слайд 2 (обложка) или 8 |
| 2 | Шаг формы «Что нужно сделать?» с задачей и тегом | слайд 9 |
| 3 | «Место опубликовано» со временем сборки карточки | слайд 12 (эффект) |
| 4 | Кандидат с процентом и расшифровкой | слайд 9 |
| 5 | Колода студента: карточка места с процентом | слайды 2, 8 |
| 6 | Сообщение бота «новый заинтересованный студент» в чате MAX | слайд 8 или 9 — доказательство, что всё живёт в MAX |
| 7 | «Это тандем!» у компании и у студента — с номером | слайды 8, 9 |
| 8 | Сообщение бота с контактом и чек-листом | слайд 8 |
| 9 | QR-плакат и сканер в колоде | слайд 11 |

**Видео** — одна запись экрана, 60–90 секунд, без звука: бот → «Я работодатель» → форма (можно ускорить) →
кандидаты → «Сменить роль» → колода → «Интересно» → приглашение → «Это тандем!» → сообщение бота. Файл —
`deck/tandem_demo.mp4`, если меньше 50 МБ, иначе — ссылка на облако в README и на служебном слайде.

Кадры кладём в `deck/screens/` (`01_bot.png` и т. д.) — их заберут в презентацию.

- Скриншоты для презентации (#19): 6–8 с телефона и 1–2 из веб-версии, в `deck/assets/`.
