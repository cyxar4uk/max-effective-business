# Как мы работаем

## Подключиться

```bash
git clone <ссылка на репозиторий>
cp .env.example .env   # значения — у Андрея в личке, НЕ в общем чате и НЕ в репозитории
```

## Ветки и коммиты

- `main` всегда рабочий: из него сдаём и деплоим.
- Работа идёт в ветке `<имя>/<что-делаю>`, например `ilya/student-feed`, `timur/bot-match-notify`.
- Коммиты пишем по-русски, в повелительном наклонении, про суть: `Добавить уведомление о взаимном интересе`.
- В `main` — только через Pull Request, **один ревьюер из команды**. На хакатоне ревью занимает минуты, а не часы;
  мелкие PR мёржим быстро.
- Документы (`docs/`, `deck/`) можно коммитить прямо в `main`.

## Секреты

- Токен бота, пароли и ключи живут **только** в `.env`, а он в `.gitignore`.
- Если секрет попал в коммит, **сразу говорим в чат**: токен перевыпускаем. Удалить его из истории мало, репозиторий уйдёт жюри.
- В `.env.example` пишем имена переменных и комментарии, без значений.

## Задачи

- GitHub Issues + доска Projects: `Todo → In progress → Review → Done`.
- У задачи один владелец. Нашёл чужой баг — заводи Issue и тегай владельца, не чини молча в своей ветке.
