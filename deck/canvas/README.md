# Исходники презентации

Копия слайдов с холста Claude Design на 25.10.2026, версия 36. Живой холст — источник правды. Правим там, а сюда
выкладываем копию после правок, чтобы история изменений была в репозитории.

- `canvas.json` — порядок и названия слайдов, три страницы: полная версия (25 слайдов), защита на 3 минуты (12),
  питч на минуту (1).
- `S*.dc.html` — полная версия, `Short*.dc.html` — короткая, `Pitch.dc.html` — питч, `Main.dc.html` — «Как проверить».
- `deck.css` — общие стили: цвета, шрифты, карточки, рамки телефона и ноутбука.

Картинки (скрины приложения, фото команды) лежат в хранилище холста и подключены как `/_blob/<id>`, поэтому вне
холста эти файлы целиком не откроются. PDF собирается экспортом с холста.

Правило из заметок холста: слайды короткой версии — копии из полной. Правишь один — правь и второй.
Модельные данные (опрос студентов, замер времени на карточку) подписаны на слайдах «модельные данные» — кейс
требует указывать смоделированные данные явно.
