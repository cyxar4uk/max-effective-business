# Исходники презентации

Копия слайдов с холста Claude Design на 25.10.2026, версия 46. Источник правды — холст: правим там, сюда
выкладываем копию после правок, чтобы команда видела изменения в истории.

## Состав

- **Полная версия — 26 слайдов** (порядок в `canvas.json`):
  - **1** — служебный «Как проверить» (`Main.dc.html`). Кейс, с. 10, требует его первым;
  - **2–25** — выступление одной линией, без приложения;
  - **26** — команда, последний слайд.
- **Питч на одну минуту** — `Pitch.dc.html`.
- `deck.css` — общие стили: один светлый фон, синий и оранжевый, шрифты Unbounded и Onest.

Короткая версия на 3 минуты больше не ведётся, её файлы из репозитория убраны.

## Текст к слайдам

- [`../speech.md`](../speech.md) — текст выступления на всю команду: кто говорит, тайминг, переходы.
- [`../summary.md`](../summary.md) — суть каждого слайда.
- [`../../docs/defense.md`](../../docs/defense.md) — вопросы жюри, правила ответов, чек-лист на 29.10.

## Важно

- Картинки подключены как `/_blob/<id>` из хранилища холста, поэтому вне холста слайды целиком не откроются.
  PDF собирается экспортом с холста.
- Смоделированные цифры (опрос студентов, замер времени на карточку) подписаны на слайдах «модельные данные»:
  кейс требует указывать их явно.
