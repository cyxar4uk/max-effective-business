# Карта критериев: как закрываем каждый пункт

Каждый пункт оценки из кейса → что мы для него делаем → где жюри это увидит → кто отвечает.
Перед сдачей идём по таблицам сверху вниз и ставим галочки. Пункт без галочки — задача на сегодня.

Где увидит: **Демо** — бот и мини-приложение в MAX · **README** · **PDF** — презентация · **Код** — репозиторий.
