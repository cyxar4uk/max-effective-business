# Фичи

Список фич MVP. Спецификации пишет Артём со своим Claude по [шаблону](_template.md): один файл на фичу,
`F-XX-название.md`. По согласованной спеке Артём ставит задачи в GitHub Issues.

Статусы: **нет спеки** → **черновик** → **согласовано** (Артём сказал «да», владельцы прочитали) → **в работе** → **готово**.

Порядок в таблице — порядок, в котором писать спеки: так идёт разработка. Разработчики не ждут спеку, если
задача понятна из `docs/03_product.md`. Спека догоняет и уточняет.
