## Предлагаемый стек (подтвердить на созвоне)

Кейс рекомендует JS и React. Команда уже работает на React + TS и Express + PostgreSQL, поэтому берём знакомое:

- **Мини-приложение:** React + TypeScript + Vite, MAX UI (React-компоненты платформы), MAX Bridge.
- **Сервер:** Node.js + TypeScript, один сервис, где живут и API для мини-приложения, и вебхук бота.
  Меньше движущихся частей — выше стабильность.
- **БД:** PostgreSQL.
- **Docker:** `db` + `server` + `miniapp` (статика за nginx). В проде перед ними reverse-proxy с TLS.

Перед стартом каждый сверяется с **актуальной** документацией MAX: кейс прямо предупреждает, что старые примеры
могут не работать.

## Структура репозитория

```
apps/miniapp/   мини-приложение (Илья)
apps/server/    API + бот (Андрей, Тимур)
docs/           кейс, варианты, решения, план
materials/      исходные материалы: кейс, ресёрч
deck/           презентация: исходники и итоговый PDF (Артём)
compose.yaml    запуск всего одной командой (Андрей)
.env.example    переменные без значений
```
