| **Тимур** | бэкенд | бот и уведомления; очередь с лимитами; расчёт совпадения с тестами; тестовые данные; импорт «Работа России» (Should); сквозной тест сценария | публикация стажировки → уведомление студенту → интерес → приглашение → оба получают сообщение от бота |

Пары для ревью: Андрей ↔ Тимур (сервер), Илья ↔ Андрей (контракт API). Артём смотрит всё, что видит пользователь.

## Стек по умолчанию

- **Мини-приложение:** React + TypeScript + Vite, MAX UI, MAX Bridge.
- **Сервер:** Node.js 24 + TypeScript, один процесс для API и бота.
- **БД:** PostgreSQL.
- **Docker:** `db` + `server` + `miniapp` (статика за nginx); в проде reverse-proxy с TLS.

Перед стартом каждый сверяется с актуальной документацией MAX (`docs/05_max_platform.md`).

## Как синхронизируемся

- В конце каждой сессии — `team/<имя>/status.md` (что сделано, дальше, блокеры, что нужно от других), коммит и пуш.
- Начало дня: `git pull` и прочитать статусы остальных.
- Баги и задачи между людьми — GitHub Issues с одним владельцем.
- Созвон 10 минут в 10:00 и 21:00. Блокер — сразу в чат, не ждём созвона.
- Решения, меняющие продукт или архитектуру, — одной строкой в [decisions.md](decisions.md).
